# pristinebaby.com ♡

A pink, kawaii photo-memory website for Pristine.

## Add photos
1. Create a folder named `photos`.
2. Put your pictures inside it.
3. Open `gallery.js`.
4. Add entries like:
   `{ src: "photos/princy1.jpg", title: "my favorite smile ♡" }`
5. Open `index.html` to preview it.

## Put it online
This is a static website, so it can be hosted on services such as GitHub Pages, Netlify, or Vercel.

For `pristinebaby.com`, buy/register the domain through a domain registrar and connect its DNS records to whichever hosting service you choose.

## Important privacy note
If the site is public, every uploaded photo may be accessible to anyone who can reach the site. For private photos, use a private/authenticated photo storage system rather than putting the original images in a public static site.
